# Elynwise — AI-Powered Web Application

An intelligent web platform featuring an integrated AI assistant. The project is a full-stack application where a powerful backend handles the AI logic, combined with a modern, fast frontend interface.

## 🛠️ Tech Stack
* **Backend:** Python, Flask
* **Frontend:** Vite, TypeScript, Tailwind CSS, HTML5 *(leveraging a modern UI boilerplate)*
* **Development Environment:** Replit Cloud IDE

## 👥 Team & Collaboration
This project was a collaborative effort, demonstrating real-world team workflow:
* **UI/UX Design:** Developed by a dedicated designer (my teammate), who created the visual identity and layout concepts.
* **Full-Stack Development (My Role):** I was solely responsible for bringing the design to life, handling both backend infrastructure and frontend implementation.

## 🚀 My Contributions
* **Backend & API Development:** Built the server architecture using Python and Flask, implementing robust API endpoints to bridge the frontend and backend.
* **Google Gemini Integration:** Successfully integrated the advanced **Gemini Flash** LLM API; built the core server-side logic for prompt handling, context streaming, and structured JSON response parsing.
* **Frontend Implementation:** Translated the design concepts into a working web interface, writing clean, type-safe TypeScript code to interact with the backend server.

## 🎨 Frontend & UI Capabilities
While the client side leverages a cutting-edge frontend setup, it ensures an exceptional user experience through:
* **Vite & TypeScript:** Provides ultra-fast Hot Module Replacement (HMR) during development and ensures type-safe, reliable component logic.
* **Component-Driven Architecture:** Designed with clean separation of concerns, managing complex states for real-time AI chat interactions.

## 💻 How to Run Locally
1. Clone the repository:
   ```bash
   git clone [https://github.com](https://github.com/Eugene6/ElynwiseAI)
   ```
2. Navigate to the project folder and install dependencies.
3. Run the backend server:
   ```bash
   python server.py
   ```
